# FileFixer Application Package

This directory contains the primary Next.js 16 App Router application for [**FileFixer**](../README.md).

## Quick Start (Within this directory)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Run automated tests (421 test cases)
npm test

# 4. Create production build (33 static routes)
npm run build
```

## Directory Structure

- `src/app/` — Next.js 16 App Router pages, layouts, and route definitions.
- `src/components/` — React UI components, navigation, modals, and tool workstations.
- `src/lib/` — 100% on-device transformation engines (image, PDF, batch, storage).
- `src/stores/` — Zustand global file and modal state stores.
- `src/types/` — TypeScript declarations and interface contracts.
- `public/` — Branding assets, vector logos, PWA manifest, and service worker.
- `tests/` — Systematic 4-tier requirement and invariant test suite.
