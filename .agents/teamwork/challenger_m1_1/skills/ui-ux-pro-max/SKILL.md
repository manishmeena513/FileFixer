## Core Methodology
- Priority 1: Accessibility (CRITICAL): Contrast >= 4.5:1 for normal text (3.0:1 for large text / UI boundaries), alt text, keyboard nav, aria-labels.
- Priority 2: Touch & Interaction (CRITICAL): Min size 44x44px hit-box, 8px+ spacing, loading feedback. No reliance on hover only.
- Priority 5: Layout & Responsive (HIGH): Mobile-first breakpoints, viewport meta, no horizontal scroll.
